\# Book Library Manager



A simple command-line book library manager written in Python.



\## Features



\- Add a book

\- View all books

\- Search books by title

\- Update reading status

\- Edit book information

\- Delete a book

\- Show reading statistics

\- Save data to a JSON file



\## How to Run



```bash

python library.py

```



\## Data Format



Books are saved in `books.json`:



```json

\[

&#x20;   {

&#x20;       "title": "Python Basics",

&#x20;       "author": "Tom",

&#x20;       "status": "reading"

&#x20;   }

]

```
